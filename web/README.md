# Interface HabitHub

React, TypeScript, CSS e Lucide. A interface usa fontes do sistema e não carrega recursos de terceiros. O Vite serve em `127.0.0.1:5173` e encaminha `/api` para `127.0.0.1:3000`. Em produção, o Compose expõe a interface e a API na mesma origem.

```sh
npm ci
npm run dev
npm run build
npm run lint
```

Inicie a API em outro terminal. Para acesso remoto e persistência, veja [self-hosting](../docs/self-hosting.md); para testar as interações, veja [acessibilidade](../docs/accessibility.md).
